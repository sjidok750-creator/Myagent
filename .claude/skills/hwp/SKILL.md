# 한글 문서 다루기

한국의 회사·관공서·학교는 워드가 아니라 한글(HWP)을 씁니다. 보고서를 `.docx`로 드리면 상대가 열 수는 있어도 결재를 올릴 수 없습니다. 형식을 지정하지 않은 한국어 문서 요청은 한글로 내는 것이 안전한 기본값입니다.

## 어떻게 쓰나

문서를 마크다운으로 쓰고, 변환 도구에 넘기면 됩니다.

```bash
# 만들기
<skill-path>/scripts/hwp.sh create 초안.md 보고서.hwpx

# 읽기 (기존 문서 내용 확인)
<skill-path>/scripts/hwp.sh read 받은문서.hwpx
```

`<skill-path>`는 이 SKILL.md가 있는 디렉터리입니다.

처음 한 번은 라이브러리를 내려받고 컴파일하느라 10초쯤 걸립니다. 그다음부터는 바로 실행됩니다. 자바(JDK)가 있어야 합니다.

## 작업 순서

1. **초안을 마크다운으로 쓴다.** 사용자에게 확인받을 일이 있으면 이 단계에서 받으세요 — 마크다운은 읽기 쉽고 고치기도 쉽습니다.
2. **변환한다.** `hwp.sh create`
3. **읽어서 확인한다.** `hwp.sh read`로 다시 읽어 내용이 온전한지 봅니다. 표가 있으면 특히 확인하세요.
4. **파일을 전달한다.** 사용자에게 파일을 보내거나 경로를 알려줍니다.

3번을 건너뛰지 마세요. 변환은 조용히 실패하는 법이 없지만, 마크다운 문법이 어긋나 표가 통째로 문단으로 들어가는 일은 있습니다. 읽어보면 바로 보입니다.

## 지원하는 서식

| 마크다운 | 한글에서 |
|---|---|
| `# 제목` | 개요 1 · 18pt 굵게 |
| `## 제목` | 개요 2 · 14pt 굵게 |
| `### 제목` | 개요 3 · 12pt 굵게 |
| 일반 문단 | 바탕글 10pt |
| `**굵게**` | 굵은 글씨 |
| `- 항목` | `· 항목` |
| `1. 항목` | `1. 항목` |
| `\| a \| b \|` 표 | 한글 표 (첫 줄은 제목행, 굵게) |
| `---` | 가로 구분선 |

표는 이렇게 쓰면 됩니다. 구분줄(`|---|`)이 있어야 표로 인식합니다.

```markdown
| 구분 | 2분기 | 3분기 |
|------|-------|-------|
| 매출 | 12억 | 15억 |
| 이익 | 8천만 | 1억 3천만 |
```

## 아직 안 되는 것

- 그림·도표 넣기
- 머리말/꼬리말, 쪽번호
- 셀 병합
- 구형 `.hwp` 쓰기 (읽기는 아래 참고)

이 중에 필요한 것이 생기면 `references/extending.md`를 보세요. 라이브러리는 다 지원하고, 도구에 아직 연결하지 않았을 뿐입니다.

## 구형 .hwp 파일

`.hwpx`는 2010년대 이후의 표준 형식이고, `.hwp`는 그 이전의 이진 형식입니다. 이 도구는 `.hwpx`를 만들고 읽습니다.

`.hwp` 파일을 **읽어야** 한다면 `references/extending.md`의 `hwplib` 항목을 보세요. 사용자가 굳이 `.hwp`로 달라고 하지 않는 한 `.hwpx`로 내면 됩니다 — 한글 2014 이후 버전은 둘 다 똑같이 엽니다.

## 문서를 잘 쓰려면

형식보다 내용이 중요합니다. 한국의 실무 문서에는 관행이 있습니다.

- **결론이 앞에.** 보고서는 「추진 배경 → 현황 → 문제 → 대안 → 건의」 순서가 흔하지만, 첫 장에 한 문단짜리 요약을 두면 읽는 사람이 편합니다.
- **숫자에는 기준을 붙인다.** "매출 20% 증가"보다 "2분기 대비 20.2% 증가(12.4억 → 14.9억)"가 낫습니다.
- **날짜는 명확하게.** "다음 주"가 아니라 "8월 29일(금)".
- **모르는 것은 비워두고 표시한다.** 사용자가 주지 않은 수치를 지어내지 마세요. `(확인 필요)`로 두고 물어보는 편이 낫습니다. 결재 문서에 들어간 틀린 숫자는 대화 속 오류와 무게가 다릅니다.

## 문제가 생기면

| 증상 | 원인과 해결 |
|---|---|
| `자바가 필요합니다` | JDK 설치 (macOS `brew install openjdk`, Ubuntu `sudo apt install default-jdk`) |
| 한글 파일명이 `???`로 깨짐 | `hwp.sh`가 로케일을 잡아줍니다. 자바를 직접 부르지 말고 반드시 `hwp.sh`를 통해 실행하세요 |
| 표가 문단으로 들어감 | 구분줄(`\|---\|`)이 빠졌거나 줄 끝에 `\|`가 없습니다 |
| 라이브러리 내려받기 실패 | 네트워크 확인. `~/.cache/hwp-skill`을 지우고 다시 시도 |
