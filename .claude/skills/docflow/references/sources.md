# 출처대장

문서에 들어가는 모든 사실이 어디서 왔는지 적어 두는 표입니다. 프로젝트 폴더에 `출처대장.md`로 저장하세요.

이 표가 없으면 검증이 불가능합니다. 검증이란 결국 **본문과 이 표를 대조하는 일**이기 때문입니다.

## 형식

```markdown
# 출처대장 — 2026년 3분기 사업계획서

작성: 2026-08-22 | 기준 시점: 2026년 3분기

| 항목 | 내용 | 출처 | 상태 |
|---|---|---|---|
| 2분기 매출 | 12억 4천만 원 | 사용자 제공 — 8/22 대화 | 확실 |
| 2분기 영업이익 | 8천만 원 | 사용자 제공 — 8/22 대화 | 확실 |
| 3분기 매출 목표 | — | 없음 | **미확인** |
| 국내 시장 규모 | 3,200억 원 | 웹 — 한국산업통계 2026.6 발표<br>https://example.kr/stat/2026 | 확실 |
| 경쟁사 점유율 | 약 18% | 웹 — 업계지 기사 2025.11<br>https://example.kr/news/123 | **오래됨** |
| 물류비 절감 목표 | 8% | 원본 문서 — 2분기 계획서 4쪽 | 확실 |

## 미확인 항목

아래는 근거가 없어 본문에 `(확인 필요)`로 남겨두었습니다.

- 3분기 매출 목표 — 확정된 수치가 있는지
- 신규 채널 계약 예정일 — 협의 중이라면 예상 시점

## 판단이 필요한 항목

- 경쟁사 점유율: 2025년 11월 자료입니다. 최신 수치를 찾지 못했습니다.
  그대로 쓰려면 "2025년 11월 기준"을 본문에 밝히는 편이 안전합니다.
```

## 상태 칸

| 상태 | 뜻 | 본문에서 |
|---|---|---|
| 확실 | 출처가 분명하고 시점도 맞음 | 그대로 씀 |
| 오래됨 | 출처는 있으나 시점이 지남 | 기준 시점을 밝히고 씀 |
| 추정 | 계산이나 추론으로 얻음 | "추정" 표시 |
| 미확인 | 근거가 없음 | `(확인 필요)`로 남김 |

## 지키면 좋은 것

**출처는 구체적으로.** "인터넷"이나 "관련 자료"는 출처가 아닙니다. 어느 기관이 언제 발표한 무엇인지 적으세요. 웹에서 찾았으면 주소도.

**대화에서 받은 것도 적으세요.** "사용자 제공"으로 끝내지 말고 날짜를 붙이면, 나중에 값이 바뀌었을 때 어느 쪽이 최신인지 알 수 있습니다.

**계산한 값은 계산식을 남기세요.** "20.2% 증가" 옆에 "(14.9-12.4)/12.4"를 적어두면 검증자가 직접 확인할 수 있습니다.

**본문과 표기를 맞추세요.** 대장에 `2026.03 ~ 2026.12`라고 적고 본문에 "2026년 3월 ~ 12월"이라고 쓰면, 같은 값인데도 대조하는 쪽에서 한 번 더 판단해야 합니다. 판단이 끼어드는 만큼 놓칠 여지가 생깁니다. 대장을 본문에 쓸 표기 그대로 적어 두세요.

**빈칸을 메우지 마세요.** 이 표에서 가장 중요한 줄은 `미확인`입니다. 그럴듯한 숫자로 채우면 표가 깔끔해 보이지만, 그 순간 이 표는 검증 도구가 아니라 알리바이가 됩니다.

## 문서를 여러 번 고칠 때

값이 바뀌면 표도 함께 고치세요. 본문과 표가 어긋나면 검증이 전부 헛돌게 됩니다.

새 정보를 받았을 때는 줄을 덮어쓰지 말고 이렇게 남기는 편이 낫습니다.

```
| 3분기 매출 목표 | 14억 9천만 원 | 사용자 제공 — 8/25 대화<br>(8/22 시점에는 미확정이었음) | 확실 |
```
