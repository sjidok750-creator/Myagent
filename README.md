# 헤뤼싀 (Harshi) — 나의 AI 비서실장

아이폰 **메시지(iMessage)** 앱과 똑같이 생긴 화면에서 대화하는, 나 한 사람만을 위한 AI 비서실장입니다.

헤뤼싀는 인도 케랄라 출신의 34세 여성입니다. 뭄바이에서 전략 컨설턴트로, 싱가포르 패밀리오피스에서 총괄 비서로 일했고, 지금은 당신의 비서실장입니다. 한국어로 말하고, 가끔 힌디어가 섞입니다.

혼자 일하지 않습니다. **여덟 개 부서**를 거느리고, **실제로 일을 합니다** — 웹을 찾아보고, 계산하고, 엑셀·문서·발표자료를 만들고, 알게 된 것을 자료실에 적어둡니다.

## 헤뤼싀가 실제로 할 수 있는 일

말만 하는 챗봇이 아닙니다. 대화 도중 필요하면 알아서 도구를 씁니다.

| 도구 | 어디서 도나 | 무엇을 하나 |
|---|---|---|
| 🔍 웹 검색 · 페이지 읽기 | Anthropic 서버 | 오늘의 사실을 직접 찾아본다. 링크를 주면 열어서 읽고 요약한다. |
| ⚙️ 코드 실행 | Anthropic 샌드박스 | 계산·표 정리·데이터 분석. 암산으로 어림잡지 않는다. |
| 📊 파일 만들기 | 코드 실행 + Agent Skills | 엑셀(xlsx)·워드(docx)·발표자료(pptx)·PDF 를 만들어 대화창에 첨부한다. |
| 📎 파일 읽기 | Files API | 사진·PDF·문서를 보내면 그대로 읽는다. 엑셀·워드는 코드로 열어서 본다. |
| 🗓️ 구글 캘린더 | 대표님 계정 | 일정을 조회·생성·수정·삭제한다. 잡기 전에 빈 시간을 먼저 확인한다. |
| ✉️ 지메일 | 대표님 계정 | 메일을 검색하고 읽는다. 답장은 **초안까지만** — 발송은 대표님이 누른다. |
| 🗂️ 비서실 자료실 | 이 기기 | 메모·할 일·사람을 적고 찾는다. **여덟 팀이 같은 자료실을 본다.** |
| 🔔 아침 브리핑 | 서버 크론 | 예약한 시각에 **헤뤼싀가 먼저** 오늘 일정과 챙길 일을 보낸다. |

실제로 이런 식으로 씁니다.

- "이번 달 지출 정리해줘" → 계산하고 **엑셀 파일**을 만들어 첨부. 요약은 자료실에 메모로 저장.
- "이 회사 어떤 곳이야?" → **웹에서 찾아보고** 출처와 함께 보고. 알게 된 사실은 메모로 남김.
- "다음 주 화요일에 미팅 잡아줘" → **할 일로 등록**. 자료실 탭에서 눈으로 확인·완료 처리 가능.
- "김파트너 기억해둬" → **사람으로 기록**. 나중에 어느 부서에서 물어도 안다.
- "IR 덱 초안 만들어줘" → **pptx 파일**로 만들어 첨부.
- 영수증 사진을 여러 장 보내고 "정리해줘" → 사진을 **읽어서** 합계를 내고 엑셀로 정리.
- 계약서 PDF를 보내고 "독소조항 있어?" → **PDF를 정독**하고 조항별로 짚어줌.
- "내일 오전 비어? 김파트너랑 10시에 잡아줘" → **실제 구글 캘린더**를 확인하고 일정 생성.
- "김파트너한테 온 메일 찾아서 답장 써줘" → **지메일 검색 → 정독 → 답장 초안**. 보내기는 내가 누름.

### 자료실 — 부서를 잇는 공용 기억

부서 대화방은 각각 독립된 대화지만, **자료실은 하나**입니다. 재무팀에 말한 내용을 일정팀도 압니다. 대화 목록 오른쪽 위 폴더 아이콘으로 열면 할 일·메모·사람을 직접 보고, 체크하고, 지울 수 있습니다.

자료실은 대화 요청마다 서버로 함께 보내지고, 헤뤼싀가 도구로 고친 결과가 되돌아와 기기에 저장됩니다. **서버는 아무것도 저장하지 않습니다.**

### 도구 끄기

설정 → "헤뤼싀가 쓸 수 있는 것" → 도구 사용을 끄면 대화만 합니다. 더 빠르고 저렴합니다. (직접 연결 모드에서는 도구를 쓸 수 없습니다 — 도구 루프는 서버에서 돕니다.)

### 파일·사진 보내기

작성창 왼쪽 **+** 를 누르면 사진 보관함과 파일에서 고를 수 있습니다. 한 번에 6개까지, 파일당 20MB 까지.

| 보낸 것 | 헤뤼싀가 하는 일 |
|---|---|
| 사진 (jpg/png/…) | 눈으로 보고 읽습니다. 보내기 전에 긴 변 1568px 로 줄여 토큰을 아낍니다. |
| PDF | 문서로 통째로 읽습니다. |
| 텍스트·CSV·JSON | 문서로 읽습니다. |
| 엑셀·워드·PPT | 코드 실행 컨테이너에 올려 코드로 열어 봅니다. |

한 번 보낸 파일은 Anthropic Files API 에 올라가고, 기기가 그 `file_id` 를 기억합니다. 같은 대화에서 다시 언급해도 **다시 업로드하지 않습니다.**

### 헤뤼싀가 만든 첨부파일

헤뤼싀가 만든 파일은 대화창에 카드로 붙습니다. 탭하면 아이폰 공유 시트가 떠서 "파일에 저장"·"메일로 보내기"를 쓸 수 있습니다. 파일 본체는 기기의 IndexedDB에 보관되고(최대 80MB, 넘치면 오래된 것부터 정리), 서버에는 남지 않습니다.

### 얼굴 사진 바꾸기

기본 아바타는 코드로 그린 일러스트입니다. 원하는 사진으로 바꿀 수 있습니다.

**설정 → 헤뤼싀 얼굴 → 사진 고르기**, 또는 대화방 오른쪽 위 ⓘ → 프로필 사진을 탭.
조직도에서 팀을 고르면 팀장 얼굴도 각각 바꿀 수 있습니다.

고른 사진은 256px 정사각형으로 잘려 **이 기기의 localStorage에만** 저장됩니다. 저장소에 커밋되지도, 서버로 올라가지도 않습니다. 언제든 "기본 일러스트로 되돌리기"로 원복됩니다.

---

부서는 두 가지 방식으로 쓸 수 있습니다.

1. **헤뤼싀 방에 그냥 던지기** — 실장이 알아서 담당 팀을 정해 처리하고, 말풍선 위에 어느 팀이 맡았는지 배지가 붙습니다.
2. **부서 방에 직접 들어가기** — 대화 목록에서 팀을 고르면 그 팀장과 1:1로 이야기합니다. 각 팀장은 자기 부서의 원칙(예: 재무팀은 계산 과정을 반드시 한 줄로 보여준다)에 따라 답합니다.

## 배포하기 (Vercel 권장)

```bash

npm install
npx vercel        # 처음 배포
```

Vercel 프로젝트 설정 → **Environment Variables** 에 넣을 값:

| 변수 | 필수 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | ✅ | [console.anthropic.com](https://console.anthropic.com) 에서 발급 |
| `ACCESS_CODE` | 선택 | 설정하면 앱 설정 화면에서 같은 코드를 입력해야 대화가 됩니다. **공개 주소로 배포한다면 반드시 넣으세요.** 안 넣으면 주소를 아는 누구나 내 API 키로 대화할 수 있습니다. |
| `HERUSHI_MODEL` | 선택 | 기본값 `claude-opus-5` |
| `GOOGLE_CLIENT_ID` | 선택 | 캘린더·지메일을 쓰려면 필요. 아래 “구글 연결하기” 참고 |
| `GOOGLE_CLIENT_SECRET` | 선택 | 위와 한 쌍 |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` / `VAPID_SUBJECT` | 선택 | 먼저 말 걸기용. `npm run vapid` 로 생성 |
| `KV_REST_API_URL` / `KV_REST_API_TOKEN` | 선택 | 알림 구독 저장소. Vercel Storage 연결 시 자동 |
| `CRON_SECRET` | 선택 | 크론이 보낸 요청만 받도록 |

### 로컬에서 돌려보기

## 구글 연결하기 (캘린더 · 지메일)

일정과 메일을 실제로 다루려면 구글 OAuth 클라이언트가 하나 필요합니다. 한 번만 만들면 됩니다.

### 1. 구글 클라우드 콘솔에서 클라이언트 만들기

1. [console.cloud.google.com](https://console.cloud.google.com) 에서 프로젝트를 하나 만듭니다.
2. **API 및 서비스 → 라이브러리** 에서 다음 둘을 사용 설정합니다.
   - Google Calendar API
   - Gmail API
3. **API 및 서비스 → OAuth 동의 화면**
   - User Type: **외부**
   - 앱 이름: 헤뤼싀 (아무거나)
   - **테스트 사용자** 에 본인 지메일 주소를 추가합니다. (게시하지 않아도 본인은 쓸 수 있습니다)
   - 범위는 따로 추가하지 않아도 됩니다. 앱이 요청할 때 함께 뜹니다.
4. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - **승인된 리디렉션 URI** 에 배포 주소를 **끝의 슬래시까지 정확히** 넣습니다.
     - 예: `https://myagent.vercel.app/`
     - 로컬 개발도 쓰려면 `http://localhost:5173/` 도 함께 추가합니다.
5. 만들어진 **클라이언트 ID** 와 **클라이언트 보안 비밀번호** 를 복사합니다.

### 2. 배포 환경변수에 넣기

```
GOOGLE_CLIENT_ID=xxxxx.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=GOCSPX-xxxxx
```

### 3. 앱에서 연결

설정 → **구글 연결** → "구글 계정 연결하기". 동의 화면에서 권한을 **모두** 허용해야 캘린더와 메일이 다 동작합니다.

### 요청하는 권한

| 범위 | 왜 필요한가 |
|---|---|
| `calendar.events` | 일정 생성·수정·삭제 |
| `calendar.readonly` | 빈 시간 확인, 일정 조회 |
| `gmail.readonly` | 메일 검색·정독 |
| `gmail.compose` | 답장 **초안** 생성 |

### 메일 발송은 왜 두 단계인가

헤뤼싀에게는 메일을 보내는 도구가 **아예 없습니다.** `gmail_draft` 로 초안만 만들 수 있습니다. 초안이 만들어지면 대화창에 카드가 뜨고, 대표님이 **보내기** 를 눌러야 `/api/google/send` 가 호출됩니다. 모델이 혼자 판단해서 메일을 보내는 경로는 코드상 존재하지 않습니다.

일정 삭제와 참석자 초대는 도구로 가능하지만, 프롬프트에서 실행 전 확인을 요구합니다.

### 토큰은 어디에 있나

구글 액세스·리프레시 토큰은 **이 기기의 localStorage** 에만 저장됩니다. 서버(`/api/google/token`)는 클라이언트 시크릿이 필요한 교환·갱신만 중계하고 토큰을 보관하지 않습니다. 대화할 때마다 기기가 액세스 토큰을 함께 보내고, 서버는 그 요청 동안만 씁니다.

연결을 끊으려면 설정 → 구글 연결 → **연결 해제** (구글 쪽 권한도 함께 회수됩니다).

## 먼저 말 걸게 하기 (아침 브리핑)

예약한 시각에 헤뤼싀가 알림으로 먼저 말을 겁니다. 알림을 탭하면 대화방이 열리고, 그 브리핑이 **말풍선으로 남아 있습니다.** 앱을 안 열어도 대화에 쌓입니다.

> **이 기능만 서버가 무언가를 저장합니다.**
> 다른 모든 것(대화·자료실·구글 토큰)은 기기에만 있지만, 헤뤼싀가 기기 없이 먼저 말을 걸려면 서버가 알림 주소를 알아야 합니다. 무엇을 저장할지는 설정에서 직접 고르실 수 있고, 알림을 끄면 서버에서 지워집니다.

### 저장되는 것

| 항목 | 언제 | 왜 |
|---|---|---|
| 푸시 구독 주소·암호화 키 | 알림을 켜면 항상 | 이게 없으면 알림을 못 보냅니다 |
| 시각·시간대·호칭 | 알림을 켜면 항상 | 언제 어떻게 부를지 |
| 미완료 할 일 목록 | "할 일 참고" 를 켰을 때만 | 브리핑에서 마감을 짚으려면 |
| 구글 갱신 토큰 | "오늘 일정 참고" 를 켰을 때만 | 브리핑에서 오늘 일정을 보려면 |

**대화 내용은 어떤 경우에도 저장되지 않습니다.**

### 설정 절차

**1. VAPID 키 만들기** (푸시 서명용, 한 번만)

```bash
npm run vapid
```

나온 세 줄을 배포 환경변수에 넣습니다.

**2. 저장소 붙이기**

Vercel 프로젝트 → **Storage** → **Upstash for Redis** 를 연결하면 `KV_REST_API_URL` / `KV_REST_API_TOKEN` 이 자동으로 들어옵니다. Upstash 를 직접 쓰신다면 `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` 도 그대로 인식합니다.

무료 등급으로 충분합니다 — 저장되는 것은 기기 하나당 1KB 남짓입니다.

**3. 크론 확인**

`vercel.json` 에 15분마다 도는 크론이 이미 들어 있습니다.

```json
"crons": [{ "path": "/api/push/tick", "schedule": "*/15 * * * *" }]
```

> **Vercel Hobby 요금제는 크론이 하루 한 번만 돕니다.** 그 경우 위 스케줄을 `0 23 * * *` 처럼 하루 한 번으로 바꾸고 (UTC 기준이니 한국 시각 08:00 은 전날 23:00), 앱의 브리핑 시각도 거기에 맞추세요. Pro 요금제면 15분 간격이 그대로 동작합니다.

`CRON_SECRET` 을 환경변수에 넣으면 Vercel 크론이 보낸 요청만 받습니다. 권장합니다.

**4. 아이폰에서 켜기**

- 반드시 **홈 화면에 추가한 아이콘**으로 열어야 합니다. 사파리 탭에서는 iOS 가 알림 권한 요청 자체를 막습니다 (iOS 16.4 이상 필요).
- 설정 → **헤뤼싀가 먼저 말 걸기** → 아침 브리핑 켜기 → 시각 선택
- **시험 알림 보내기** 로 바로 확인해 보세요.

### 브리핑에 무엇이 담기나

헤뤼싀가 대화창에서와 똑같은 인격으로 3~5문장을 씁니다. 오늘 일정 중 가장 중요한 것 하나를 짚고, 마감이 임박한 할 일을 알리고, 오늘 무엇부터 하면 좋을지 한 줄 제안합니다. **위에 없는 사실은 지어내지 않도록** 프롬프트에서 못박았습니다 — 캘린더를 공유하지 않으셨다면 일정 이야기를 아예 꺼내지 않습니다.

같은 날 두 번 가지 않고, 예약 시각을 90분 넘게 지나면 그날은 거릅니다 (한밤중에 아침 인사를 하지 않도록).

## 두 가지 연결 모드

설정 화면에서 고릅니다.

- **서버 프록시** (기본, 권장) — 브라우저는 `/api/chat` 만 호출하고, API 키는 서버 환경변수에만 있습니다. 키가 기기에 남지 않습니다.
- **직접 연결** — 서버 없이 브라우저가 Anthropic API를 직접 호출합니다. GitHub Pages 같은 정적 호스팅에서도 돌아가지만, **API 키가 이 기기의 localStorage에 저장됩니다.** 내 폰에서만 쓰세요.

---

## 대화는 어디에 저장되나

대화·자료실·구글 토큰은 이 기기의 `localStorage` 에, 첨부파일은 `IndexedDB` 에만 저장됩니다. 서버(`/api/chat`)는 요청을 받아 Anthropic으로 전달하고 도구를 돌린 뒤 결과를 돌려줄 뿐, 아무것도 기록하지 않습니다.

**단 하나의 예외는 아침 브리핑입니다.** 헤뤼싀가 기기 없이 먼저 말을 걸려면 서버가 알림 주소를 알아야 하므로, 그것만 저장됩니다 (위 “먼저 말 걸게 하기” 참고). 대화 내용은 그때도 저장되지 않습니다. 기기를 바꾸면 대화는 따라오지 않습니다. 설정 화면에서 대화방별로, 또는 전부 지울 수 있습니다.

## 만들어진 기능

- iMessage 말풍선 (꼬리, 연속 메시지 묶음, 파란/회색, 라이트·다크)
- 스트리밍 응답 — 글자가 실시간으로 찍힙니다. 중간에 멈출 수 있습니다.
- 타이핑 인디케이터, 전달됨 표시, 날짜 구분선
- 길게 눌러 탭백(❤️👍👎😂‼️❓)
- 대화 목록 · 고정 대화 · 검색 · 안 읽음 표시
- 부서 배지 — 헤뤼싀가 어느 팀에 넘겼는지 말풍선 위에 표시
- 빈 대화방의 추천 질문 칩
- 실패 시 오류 말풍선 + 다시 시도
- 웹 검색·코드 실행·파일 생성 — 도구를 쓰는 동안 "웹을 찾아보는 중…" 이 실시간으로 보임
- 사진·PDF·문서 첨부 — 작성창 + 버튼, 보낸 사진은 말풍선에 그대로
- 구글 캘린더 일정 관리, 지메일 검색·정독·답장 초안
- 메일 발송 확인 카드 — 헤뤼싀는 초안까지만, 발송은 사람이
- 아침 브리핑 — 예약 시각에 헤뤼싀가 먼저 알림을 보내고, 그 내용이 대화에 남음
- 엑셀·문서·발표자료 첨부와 저장
- 부서를 잇는 공용 자료실 (할 일·메모·사람)
- 얼굴 사진 지정 — 헤뤼싀와 각 팀장의 아바타를 내 사진으로 교체
- 홈 화면 추가(PWA), 오프라인에서도 앱은 열림
- 접속 코드, 요청 레이트 리밋
