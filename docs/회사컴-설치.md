# 회사컴(Windows)에 헤뤼싀 올리기

30분 잡으면 됩니다. 순서대로 하고, 막히면 그 화면을 폰으로 찍어 Claude 에게 보여주세요.

## 0. 준비물 확인

PowerShell 을 엽니다 (시작 메뉴에서 "PowerShell" 검색 · 관리자 권한 불필요).

```powershell
node -v      # v18 이상이면 통과
git --version
claude --version
java -version
```

없는 것만 아래에서 채웁니다.

| 없을 때 | 설치 |
|---|---|
| node | [nodejs.org](https://nodejs.org) → LTS 내려받아 설치 |
| git | [git-scm.com/downloads/win](https://git-scm.com/downloads/win) — **꼭 설치.** 이게 있어야 Claude 가 Bash 를 쓰고, 한글 문서 스킬이 Bash 로 돕니다 |
| claude | PowerShell 에서 `irm https://claude.ai/install.ps1 \| iex` |
| java | [adoptium.net](https://adoptium.net) → LTS. 한글(HWP) 문서용 — 나중에 해도 됩니다 |

설치 후 PowerShell 을 **닫았다 다시 열어야** 새 명령이 잡힙니다.

## 2. 헤뤼싀 받기

```powershell
cd $env:USERPROFILE\Documents
git clone https://github.com/sjidok750-creator/Myagent.git
```

## 3. 스킬 깔기 (한글 문서 등)

```powershell
git clone https://github.com/sjidok750-creator/worktools.git
mkdir -Force $env:USERPROFILE\.claude\skills
Copy-Item -Recurse -Force worktools\skills\hwp $env:USERPROFILE\.claude\skills\
Copy-Item -Recurse -Force worktools\skills\docflow $env:USERPROFILE\.claude\skills\
Copy-Item worktools\규칙\CLAUDE.md $env:USERPROFILE\.claude\CLAUDE.md
```

> 마지막 줄은 `.claude\CLAUDE.md` 가 이미 있으면 덮어씁니다. 이 컴퓨터에서
> Claude 를 처음 쓰는 거라면 그냥 실행하면 되고, 아니라면 먼저 열어보세요.

## 4. 켜기

```powershell
cd $env:USERPROFILE\Documents\Myagent
$env:HERUSHI_HOME="C:\회사업무"        # 헤뤼싀의 작업 폴더 (실제 경로로 바꾸세요)
$env:HERUSHI_CODE="원하는접속코드"; npm run herushi
```

`HERUSHI_HOME` 은 헤뤼싀가 사는 폴더입니다. **평소 프로젝트 폴더들의 상위(회사업무)로 잡으세요** — 그래야 폰에서 "수리2교 회의록 어디까지 됐어?"처럼 모든 프로젝트를 물을 수 있고, 헤뤼싀가 만든 파일이 실제 업무 폴더에 남아 책상의 클로드 코드와 이어집니다. 안 정하면 `내 문서\헤뤼싀비서실` 이라는 별도 폴더를 씁니다.

> 이 폴더 안에서는 헤뤼싀가 파일을 만들고 고칠 수 있습니다. 그게 목적이지만,
> 건드리면 안 되는 폴더가 섞여 있다면 그건 밖에 두세요.

- 처음 켤 때 **Windows 방화벽 창**이 뜹니다 → "개인 네트워크" 체크하고 **허용**.
  (거부했다면: Windows 보안 → 방화벽 → 앱 허용에서 Node.js 를 켭니다)
- 화면에 `휴대폰에서 http://<IP>:5177` 이 나옵니다.

이 PowerShell 창을 닫으면 헤뤼싀도 꺼집니다. 창은 켜 둡니다.

### 더블클릭으로 켜기 (권장)

매번 명령을 치지 않으려면 한 번만 준비해 두세요.

1. `Myagent` 폴더의 `헤뤼싀설정.예시.bat` 을 복사해 **`헤뤼싀설정.bat`** 으로 이름을 바꿉니다
2. 메모장으로 열어 두 줄을 고칩니다 — `HERUSHI_HOME` (작업 폴더), `HERUSHI_CODE` (접속 코드)
3. 이제부터는 **`헤뤼싀.bat` 을 더블클릭**하면 켜집니다

이 창을 닫으면 헤뤼싀가 잠듭니다. 대화 기억과 파일은 그대로 남고, 다시 켜면 이어집니다.

**컴퓨터 켤 때 자동으로 켜지게** 하려면: `헤뤼싀.bat` 을 오른쪽 클릭 → 바로 가기 만들기 → 그 바로 가기를 잘라내기 → `Win+R` 에 `shell:startup` 입력 → 열린 폴더에 붙여넣기.

> `헤뤼싀설정.bat` 에는 접속 코드가 들어 있어 저장소에 올라가지 않습니다.

## 5. 아이폰 연결

1. 아이폰을 **같은 네트워크**(회사 와이파이)에 연결
2. 사파리로 위 주소를 연다
3. 공유 버튼 → **홈 화면에 추가**
4. 홈 화면 아이콘으로 열고 → 설정 → 접속 코드에 4번에서 정한 코드 입력
5. 헤뤼싀에게 아무 말이나 걸어본다

**폰에서 주소가 안 열리면** 십중팔구 회사 와이파이가 기기끼리 통신을 막는
것입니다(AP 격리). 아래 Tailscale 로 해결됩니다.

## 5.5. 검증 친구 붙이기 (선택 · ChatGPT 유료 구독 필요)

헤뤼싀의 결과를 OpenAI 코덱스가 같은 대화방에서 교차 검토하게 합니다.
지적이 오면 헤뤼싀가 원본을 다시 확인해 고치거나 근거를 들어 반박합니다.

```powershell
npm install -g @openai/codex
codex login        # 브라우저가 열리면 ChatGPT Plus/Pro 계정으로
```

로그인까지 마친 뒤 헤뤼싀 서버를 껐다 켜면, 시작 화면에
`검증 친구  코덱스 — 결과를 교차 검토합니다` 가 뜹니다. 그게 확인입니다.

ChatGPT 구독이 없으면 이 단계는 건너뛰세요 — 헤뤼싀는 검증 없이 그대로
돌고, docflow 스킬의 자체 검증(서브에이전트)은 여전히 씁니다.

## 6. Tailscale — 회사 밖에서도, 집 맥북에서도

[tailscale.com](https://tailscale.com) 무료 계정 하나로:

1. 회사컴에 Tailscale 설치 → 로그인
2. 아이폰에 Tailscale 앱 설치 → 같은 계정 로그인
3. 집 맥북에도 설치 (선택)
4. 회사컴의 Tailscale IP(100.x.x.x)를 확인해서, 폰에서
   `http://100.x.x.x:5177` 로 접속 → 홈 화면에 다시 추가

이러면 집에서든 밖에서든 회사컴만 켜져 있으면 헤뤼싀가 응답합니다.

## 7. 꺼지지 않게

- 설정 → 시스템 → 전원 → **절전 모드: 안 함** (화면 끄기는 상관없음)
- 컴퓨터가 자면 헤뤼싀도 잡니다

## 자주 걸리는 것

| 증상 | 해결 |
|---|---|
| `irm 은(는) ... 아닙니다` | CMD 창입니다. PowerShell 을 여세요 (프롬프트가 `PS C:\` 로 시작해야 함) |
| `claude : 용어가 인식되지 않습니다` | PowerShell 을 닫았다 다시 열기 |
| 폰에서 접속 안 됨 | ① 방화벽 허용 확인 ② 같은 와이파이인지 ③ 안 되면 Tailscale (6번) |
| 답이 "Claude Code 실행에 실패" | 서버 PowerShell 창의 로그를 찍어 Claude 에게 |
| 한글 파일명이 깨짐 | java 를 설치했는지, hwp.sh 를 통해 실행했는지 확인 |

## 보안 메모

  요구). 켜 두는 동안은 본인만 쓰는 컴퓨터라는 전제입니다.
- 포트포워딩으로 인터넷에 직접 열지 마세요. 밖에서 쓰려면 Tailscale(6번)로.
